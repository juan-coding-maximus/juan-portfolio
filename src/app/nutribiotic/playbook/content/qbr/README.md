# QBR · the evidence file

One file per quarter, named `YYYY-QN.md`. This folder is where the Director case
(and later the VP case) is built: written, dated, numeric. First QBR due
2026-11-01 (G6).

## Template

```
# QBR YYYY-QN

## The number
Trailing-12-month ordering accounts: <n> (baseline 61 at 2026-08-02).
Reactivations this quarter: <n>. Overdue list size: <n>.

## Goals, red/yellow/green
G1 Territory: <RAG> <one paragraph>
G2 Playbook: <RAG> <one paragraph>
G3 Seasonal engine: <RAG> <one paragraph, campaign ROI tables linked>
G4 In-store: <RAG> <one paragraph, pilot numbers>
G5 Stack: <RAG> <one paragraph>
G6 Team & case: <RAG> <one paragraph>

## Decisions taken / needed
<targets re-confirmed or re-set; `proposed` labels retired here>

## What goes in the promotion file
<the one or two artifacts from this quarter a Director conversation cites>
```

Numbers come from the OS and receipts; a QBR paragraph with a number that has no
source does not ship.

Monthly, between QBRs: one paragraph per goal appended to the current quarter's
draft, RAG-flagged. Twenty minutes, not a ceremony.
