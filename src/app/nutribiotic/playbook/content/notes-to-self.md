# Notes to Self

The running list of things learned in the field that are worth carrying to
every account of that shape, not just the one they came from. Same rule as
the rest of the shelf: a note stays here because it held up more than once,
not because it sounded right the first time it worked.

## Prospecting

- **Phone first, for both new and revived accounts.** A call opens a new
  prospect and a dormant one the same way: it tests interest before a drive
  is spent on a door that was never going to open. Use the call to qualify,
  then route the visit.
- **Scope the area before committing to any vitamin shop.** A single vitamin
  shop stop is rarely worth a special trip on its own; check what else sits
  in range first (other independents, clinics, gyms, specialty grocery) and
  decide the stop as part of a cluster, not in isolation.

## Value propositions by account type

One line each: the pitch that opened the door, kept for reuse on the next
account of the same type. Add to this list rather than starting over per
visit.

- **Beauty spas, non-soap cleanser:** lead with sensitive skin. It is the
  clearest value proposition for this account type and the one that gets a
  yes fastest.
- **Athletic / performance-focused spots, collagen line:** lead with collagen
  production. Position the pea protein mixed with vitamin C and electrolytes
  as what actually supports that production, not just protein content on its
  own.
